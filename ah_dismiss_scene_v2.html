Dismiss Scene V2

Dismiss a currently visible Scene V2.

Set Screen ID to the ID of the scene you want to dismiss. This is the same ID that was used (or auto-assigned) when the scene was shown with the Show Scene V2 action.

If Screen ID is left empty, all currently visible Scene V2 screens will be dismissed.

Check Scenes V2 (Screen Builder) Manual for full details on how Scenes V2 work.
